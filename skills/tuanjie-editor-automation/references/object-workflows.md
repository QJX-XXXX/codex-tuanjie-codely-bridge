# Object Workflows

## Scene、GameObject 和组件

1. 读取目标 Scene、层级、对象标识、现有组件、关键字段、引用和脏状态。
2. 确认对象范围和动作是用户授权的最小变化；不因名称相似扫描或修改全场景。
3. 使用当前 `tuanjie` schema 中真实存在的对象语义能力执行一个动作。
4. 重新读取对象、组件、字段和引用；检查重复对象、重复组件、丢失引用和意外层级变化。
5. 按需保存 Scene，再重新读取保存结果。

## Prefab

先确认操作发生在 Prefab Asset 还是实例，读取 Override、嵌套关系和引用。修改后重新读取 Prefab、实例和 Override；Apply、Revert、覆盖和批量重建属于高风险操作，范围不清或前次结果未确认时停止，不盲重试。

## 资源、ScriptableObject、材质和 Importer

先读取目标路径、类型、Importer 设置和引用关系。只修改用户点名的字段，完成后重新读取序列化值、Importer 和依赖对象；需要保存时保存明确目标，不重建无关资源。

## 最小动作示例

用户要求“给已确认的 `Player` 添加一个现有组件”时，先读取唯一 `Player` 和现有组件列表；添加后再次读取组件列表和关键字段，确认没有重复组件，再保存所属 Scene 并复读保存状态。
