# 验证工作流参考

## Scene/Prefab/组件

确认项目根和 Editor
→ 读取目标对象、层级、引用和脏状态
→ 执行一个最小动作
→ 重新读取对象和关键属性
→ 检查重复对象、组件、引用
→ 按需保存
→ 重新读取保存后的状态

如果连接调用失败，先读取确认是否部分成功；只有幂等操作可使用原参数重试一次。删除、覆盖、Apply Prefab、批量重建等操作在结果未确认前禁止盲重试。

## C# 脚本后附加组件

文件写入
→ 等资源刷新
→ 等编译和 Domain Reload 稳定
→ 读取 Console/编译结果
→ 有新错误：停止对象操作
→ 类型可用后再读取目标 GameObject
→ 添加组件
→ 重读组件、字段和引用
→ 保存并确认

不得把“脚本文件已经写入”当作“类型已经可用”，也不得在 Editor 正在导入、编译、切换 Play Mode 或保存时并发提交冲突操作。

## 完成报告

分别列出：已完成文件/资源修改、编译状态、相关测试、Editor 重新读取与保存验证、失败/重试/回退、风险假设和未覆盖验证。没有证据就不要声称完成。
